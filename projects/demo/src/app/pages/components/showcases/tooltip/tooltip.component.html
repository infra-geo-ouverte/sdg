L'infobulle est utilisée pour fournir des informations contextuelles liées à un élément particulier. Pour plus d'information, voir l' du Système de design gouvernemental.

Généralités

Les infobulles s'utilisent principalement dans les formulaires. Elles fournissent des informations complémentaires ou des précisions.

Deux variantes sont disponibles selon le type d'information à présenter :

  • Pour une définition;
  • Pour une précision sur un champ.

Configuration

Il existe quatre input différents pouvant être configurés :

  • title : le titre (facultatif) de l'infobulle;
  • icon : l'icône de l'infobulle - info (valeur par défaut) ou help;
  • position : la position de l'infobulle - right (valeur par défaut), left, top ou bottom;
  • buttonTooltip : la mention affichée au survol du bouton de l'infobulle.

Si l'espace nécessaire pour afficher l'infobulle est insuffisant selon l'input position, elle sera automatiquement repositionnée.

De plus, si la boîte de l'infobulle est visible lors du défilement de la page courante et que le bouton de l'infobulle est hors de la zone visible, l'infobulle se fermera automatiquement.
