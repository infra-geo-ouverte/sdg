La carte complète prend la totalité de l'espace de la fenêtre du navigateur et permet plusieurs interactions. Pour plus d'information, voir la du Système de design gouvernemental.

Elle est utilisée lorsqu'une vue d'ensemble des données géospatiales est pertinente pour l'utilisateur, et lorsque des interactions plus complexes sont nécessaires.

Recherche

La barre de recherche doit être visible en tout temps (elle est activée par défaut (search: true)). Lorsqu'une recherche est initiée, le panneau principal s'ouvre pour montrer la liste des résultats.

Configuration

Il est possible de remplacer le panneau de résultats par défaut en projetant un ng-template avec la directive sdgPanelContent="search".

Le contexte suivant est accessible dans le ng-template :

  • $implicit / groups — SearchResultGroup[] : groupes de résultats, un par source de recherche enregistrée. Chaque groupe expose source, results, loading et page.
  • loading — boolean : true tant qu'au moins une source est encore en train de charger des résultats.

Panneau

Le panneau principal permet de présenter le contenu d'accueil et informationnel d'une carte complète, ainsi que certaines des actions qu'il est possible d'y réaliser.

Les informations qui s'y trouvent sont essentielles à la tâche; elles doivent être claires, concises et se limiter à du contenu textuel.

Configuration

Plusieurs types de contenu (ou variantes) peuvent être projetés avec la directive sdgPanelContent en précisant le type : "search", "legend" ou toute autre valeur personnalisée.

L'option panel.default permet de définir la variante par défaut à utiliser lorsqu'on quitte la recherche ou la légende. Si elle n'est pas définie, le panneau se ferme simplement. Le PanelService permet de contrôler l'état du panneau programmatiquement.

Outils d'interaction

Les outils d'interaction correspondent aux actions complexes ayant une incidence sur l'affichage et le traitement des données. Il peut s'agir, par exemple, d'outils de mesure, de personnalisation des données et de tracés. Ces outils sont représentés par des boutons situés dans le coin inférieur gauche de la carte, au-dessus du bouton de Fonds de carte.

Cette fonctionnalité n'est pas encore implémentée.

Outils de navigation

Les outils de navigation correspondent aux interactions permettant à l'utilisateur de se positionner dans la carte. Ces outils n'ont pas d'incidence sur les données. On y retrouve les boutons de géolocalisation, ainsi que les niveaux de zoom, par exemple.

Configuration

Chaque outil est activé par défaut et peut être désactivé individuellement. La barre d'échelle (scaleLine) s'affiche dans le coin inférieur gauche au format bureau et dans le coin supérieur droit au format mobile.

Fonds de carte

Le sélecteur de fond de carte s'affiche dans le coin inférieur gauche lorsqu'au moins deux couches sont fournies via l'option basemaps.

Configuration

Légende

Le bouton de légende s'affiche en bas à droite de la carte lorsque l'option legend: true est définie. Son contenu est fourni par projection via sdgPanelContent="legend".

Configuration

Pied de page

Les éléments obligatoires du pied de page sont présentés textuellement :

  • la signature du ministère ou de l'organisme émetteur de la carte;
  • la mention «© Gouvernement du Québec, [date de première publication]».

Configuration

Le pied de page s'affiche en bas de la carte et présente les informations d'attribution : droit d'auteur, organisation responsable et date de première publication. Il est configuré via l'option footer.

  • copyright — libellé et URL du droit d'auteur (par défaut : « © Gouvernement du Québec »);
  • organization — nom et URL de l'organisation responsable (obligatoire);
  • firstPublicationDate — date ou année de première publication (optionnel).

Traduction des libellés

Tous les libellés affichés par la composante (barre de recherche, panneau, outils de navigation, fonds de carte, légende) peuvent être personnalisés.

Configuration

Trois mécanismes sont disponibles, par ordre de priorité croissante :

  1. Liaison d'entrée localisé : passer un objet SdgFullMapLabels directement via [labels] sur la balise <sdg-ol-full-map>. Prend le dessus sur le jeton d'injection.
  2. Jeton d'injection global : fournir SDG_FULL_MAP_LABELS dans les providers du composant ou de la route pour remplacer les libellés pour toutes les instances.
  3. Jeton d'injection global : est compatible avec provideTranslatedLabels pour brancher le TranslationService.
