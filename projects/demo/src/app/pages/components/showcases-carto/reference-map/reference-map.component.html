La carte de référence correspond à une vignette cartographique permettant la localisation ou la mise en contexte d'un sujet. Elle est placée dans une page informationnelle. Pour plus d'information, voir la du Système de design gouvernemental.

Ce support visuel est utilisé pour améliorer la compréhension des informations présentées dans la page et fournir un contexte géographique.

Configuration

Interactions

La carte de référence est optimisée pour une navigation fluide sur tous les appareils.

Certaines interactions sont bloquées et un message d'aide apparait indiquant l'interaction à réaliser. Le message s'affiche pour une durée de 2 secondes.

  • Avec la souris, le zoom est bloqué lors du défilement;
  • Sur appareil avec écran tactile, le déplacement est bloqué au défilement à un doigt.

Comportement des fonds de carte

Le composant utilise des fonds de carte intégrées et applique un fond par défaut si aucun n'est fourni.

Les clés intégrées disponibles sont topo, imagery et hybrid.
