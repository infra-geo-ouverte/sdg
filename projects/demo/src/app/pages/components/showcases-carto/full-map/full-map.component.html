1. Recherche

La barre de recherche est activée par défaut (search: true). Lorsqu'une recherche est initiée, le panneau principal s'ouvre et affiche la liste des résultats. Il est possible de remplacer le panneau de résultats par défaut en projetant un ng-template avec la directive sdgPanelContent="search".

Le contexte suivant est accessible dans le ng-template :

  • $implicit / groups — SearchResultGroup[] : groupes de résultats, un par source de recherche enregistrée. Chaque groupe expose source, results, loading et page.
  • loading — boolean : true tant qu'au moins une source est encore en train de charger des résultats.

2. Panneau

Le panneau latéral (bureau) ou inférieur (mobile) affiche le contenu associé à l'onglet actif. Plusieurs contenus peuvent être projetés avec la directive sdgPanelContent en précisant le type : "search", "legend" ou toute chaîne personnalisée. La largeur du panneau en bureau est configurable via panel.width (par défaut : 380 px).

L'option panel.default permet de définir le panneau par défaut vers lequel revenir lorsqu'on quitte la recherche ou la légende. Si non défini, le panneau se ferme simplement. Le PanelService permet de contrôler l'état du panneau programmatiquement.

3. Outils d'interaction

Les outils d'interaction correspondent aux actions complexes ayant une incidence sur l'affichage et le traitement des données (mesure, personnalisation, tracés, etc.). Ils sont représentés par des boutons dans le coin inférieur gauche de la carte, au-dessus du bouton des fonds de carte.

Cette fonctionnalité n'est pas encore implémentée.

4. Outils de navigation

Les outils de navigation sont situés dans le coin inférieur droit et permettent à l'utilisateur de se positionner dans la carte (géolocalisation, retour à l'étendue initiale, rotation, niveaux de zoom). Chaque outil est activé par défaut et peut être désactivé individuellement. La barre d'échelle (scaleLine) s'affiche en bas gauche de la carte ou en haut droit sur mobile.

5. Fonds de carte

Le sélecteur de fond de carte s'affiche dans le coin inférieur gauche lorsqu'au moins deux couches sont fournies via l'option basemaps.

6. Légende

Le bouton de légende s'affiche en bas à droite de la carte lorsque l'option legend: true est définie. Son contenu est fourni par projection via sdgPanelContent="legend".

7. Pied de page

Le pied de page s'affiche en bas de la carte et présente les informations d'attribution : droit d'auteur, organisation responsable et date de première publication. Il est configuré via l'option footer.

  • copyright — libellé et URL du droit d'auteur (par défaut : « © Gouvernement du Québec »).
  • organization — nom et URL de l'organisation responsable (obligatoire).
  • firstPublicationDate — date ou année de première publication (optionnel).

8. Traduction des libellés

Tous les libellés affichés par la composante (barre de recherche, panneau, navigation, fonds de carte, légende) peuvent être personnalisés. Trois mécanismes sont disponibles, par ordre de priorité croissante :

  1. Liaison d'entrée localisé : passer un objet SdgFullMapLabels directement via [labels] sur la balise <sdg-ol-full-map>. Prend le dessus sur le jeton d'injection.
  2. Jeton d'injection global : fournir SDG_FULL_MAP_LABELS dans les providers du composant ou de la route pour remplacer les libellés pour toutes les instances.
  3. Jeton d'injection global  est compatible avec provideTranslatedLabels pour brancher le TranslationService.
